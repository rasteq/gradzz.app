## ✦ Overview

**Gradzz** ([gradzz.app](https://gradzz.app/)) is an ultra-fast, modern, client-side academic GPA & CGPA calculator custom-engineered specifically for students of **National University Bangladesh** (জাতীয় বিশ্ববিদ্যালয়).

Navigating complex academic regulations across 4 years of Honours, Degree Pass, and Masters programs—especially spanning multiple curriculum syllabus reforms (2013–2014 & 2024–2025)—can be daunting. Gradzz eliminates the confusion with zero required logins, zero ads, zero data tracking, and instantaneous mathematical precision.

<br/>

## ✦ Key Highlights & Features

- ⚡ **Instant Multi-Year CGPA Calculation**  
  Calculates cumulative GPA across 1st, 2nd, 3rd, and 4th academic years with automated credit weighting, syllabus detection, and real-time validation.

- 📜 **Official Syllabuses Supported**  
  Full support for both the legacy **2013–2014** and newly revised **2024–2025** curriculum syllabus structures for all major departments and programs.

- 📄 **Luxury PDF Marksheet & Official Transcript Generator**  
  Exports high-resolution, print-ready formal academic marksheets and full 4-year cumulative transcripts directly from the browser (powered by defensive `jsPDF` & `html2canvas` engines).

- 🎨 **Shareable High-Resolution Result Cards**  
  Generates beautiful social achievement cards featuring the student's name, department badge, year-wise breakdown, and final CGPA classification.

- 🎯 **Target CGPA & Grade Prediction Planner**  
  Determines the exact future GPA and course grades required to reach desired honors milestones (e.g., First Class, 3.00, 3.50+).

- 🌓 **OLED-Tuned Dark & Light Themes**  
  Engineered with high-contrast accessibility, ambient glow effects, responsive navigation docks, and seamless theme persistence.

- 📱 **Fluid Mobile-First Responsive Experience**  
  Designed from the ground up for smartphones, tablets, and desktops with momentum scrolling, natural touch interactions, and zero layout shift.

- 🔒 **100% Privacy & Offline-First Integrity**  
  Runs completely client-side in the browser. No student marks, names, or roll numbers ever leave your device.

## ✦ Architecture & Technology

Gradzz is engineered with a hyper-lean footprint, ensuring instant loading even on low-bandwidth mobile connections:

| Component | Technology | Description |
| :--- | :--- | :--- |
| **Core Architecture** | Semantic HTML5 & Modern CSS3 | Unified, reactive single-page architecture |
| **Computational Engine** | Pure Vanilla ES6+ | Real-time weighted credit calculation & grading validation |
| **Document Generation** | `jsPDF` + `html2canvas` | High-fidelity vector/raster PDF transcript compiler |
| **Motion & Scroll** | `Lenis` Scroll Engine | Smooth 60fps momentum physics across viewports |
| **Visual Delight** | Inlined Canvas Confetti Engine | Zero-dependency celebration animations |
| **Typography** | Plus Jakarta Sans & Hind Siliguri | Optimized multilingual typographic hierarchy |

## ✦ Getting Started Locally

No complex build steps, package managers, or bundlers are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rasteq/gradzz.app.git
   cd gradzz.app
   ```

2. **Open in any browser:**
   Double-click `index.html` or serve via any static web server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js npx
   npx serve .
   ```

3. Navigate to `http://localhost:8000` in your browser.
